# DevOS — Project Overview

## Purpose

DevOS is a personal Developer Operating System: a calm, minimal workspace for tracking projects, tasks, goals, GitHub activity, focus sessions, and useful AI assistance.

The product should help answer one question quickly:

> What should I work on next?

## Product Principles

1. **Minimal by default** — show only decision-useful information.
2. **Progressive disclosure** — details appear when requested.
3. **One visual language** — use the shared design system everywhere.
4. **Responsive from day one** — mobile, tablet, laptop, desktop, and large displays are first-class.
5. **Useful AI** — AI should reduce work, not decorate the UI.
6. **Real data first** — integrations must have clear loading, empty, error, and success states.
7. **Maintainable code** — prefer simple abstractions over clever architecture.

## Primary User

A developer who works on multiple projects and wants one place to understand current work, progress, GitHub activity, and goals.

## Core Areas

- Overview
- Projects
- Tasks
- GitHub
- Analytics
- Goals
- Focus
- AI
- Settings

## Non-Goals

Do not turn DevOS into:

- a full enterprise project-management suite
- a social network
- a generic AI chatbot
- a page full of charts
- a clone of GitHub
- a clone of Notion

## Success Criteria

A user should be able to open DevOS and understand within seconds:

- what needs attention
- what they are currently building
- how active they have been
- what their next meaningful action is

## Repository Context

The project is intended to continue from an existing repository. Preserve legitimate existing history and working functionality unless there is a clear reason to replace it.

Do not rewrite history or fabricate historical development activity.
