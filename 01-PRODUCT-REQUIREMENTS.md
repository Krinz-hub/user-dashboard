# DevOS — Product Requirements

## 1. Dashboard

The dashboard is the primary workspace.

### Must show

- current focus
- up to four key metrics
- recent activity
- active projects
- upcoming goals/tasks

### Must not show

- long explanatory paragraphs
- every available statistic
- duplicate information
- raw API payloads

### Dashboard information hierarchy

1. Current action
2. Important status
3. Recent activity
4. Active projects
5. Secondary insights

## 2. Projects

Users can:

- create projects
- edit projects
- archive projects
- assign status
- define milestones
- connect repositories
- track progress
- add technologies
- view project activity

Project statuses:

- Planning
- Building
- Paused
- Completed
- Archived

## 3. Tasks

Tasks support:

- title
- optional description
- status
- priority
- project
- labels
- due date

Statuses:

- Backlog
- Todo
- In Progress
- Done

Priorities:

- Low
- Medium
- High
- Urgent

## 4. Goals

Support:

- daily goals
- weekly goals
- monthly goals
- yearly goals

A goal contains a measurable target and current progress.

## 5. Focus

Focus mode provides:

- selected task/project
- timer
- start/pause/finish
- completed focus sessions
- optional notes

The focus screen must remain intentionally minimal.

## 6. GitHub

Support:

- GitHub profile
- repositories
- contribution activity
- commits
- pull requests
- issues
- stars
- forks
- language distribution

GitHub data should be summarized instead of dumped onto the user.

## 7. Analytics

Analytics should answer useful questions:

- How active was I?
- What projects received attention?
- How has activity changed?
- How many tasks were completed?
- What is my project velocity?

Time ranges:

- 7 days
- 30 days
- 90 days
- 1 year

## 8. AI

AI capabilities should include:

- project planning
- task breakdown
- weekly review
- project health analysis
- concise development summaries

AI output must be short, actionable, and editable.

## 9. Settings

Settings:

- profile
- appearance
- GitHub connection
- notifications
- preferences
- security
- account

## Feature Priority

### P0

- authentication
- dashboard
- projects
- tasks
- responsive UI
- design system

### P1

- GitHub
- goals
- analytics
- focus

### P2

- AI features
- advanced integrations
- public profile
- shareable analytics
